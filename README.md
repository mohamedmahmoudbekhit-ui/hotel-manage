# Hotel Management

check my google sheets, you will find Monthly report, please check it and take it as a reference and do the following :
Build a modern, clean, and fully automated Hotel / Guest House Management System optimized for Google Sheets–style usability and dashboard analytics.

The system should include the following modules:

📁 1. Bookings (Monthly Sheet)

Create a structured monthly booking table with improved UX and automation.

 Clean and organized layout

 Dropdown menus for:

 Booking Type (Airbnb / Booking / Offline)

 Room Selection

 Status (Confirmed / Pending / Cancelled)

 Auto color coding based on booking type and status

 Automatic calculations for:

 Price totals

 Revenue per booking

 Validation rules to prevent errors

 Mobile-friendly table design

📊 2. Dashboard (Main Overview)

Create a dynamic dashboard that updates automatically from all bookings.

Include KPI cards for:

 Total Revenue

 Revenue from Booking.com

 Revenue from Airbnb

 Revenue from Offline bookings

 Total Number of Bookings

 Occupancy Rate (%)

 Best Performing Room

 Average Revenue per Booking

 Empty Days per Room

Design requirements:

 Modern KPI cards layout

 Clean spacing and visual hierarchy

 Auto-updating values with formulas or linked data

📈 3. Charts Section

Add interactive charts for better insights:

 Pie Chart: Distribution of bookings by type

 Bar Chart: Revenue comparison by source (Airbnb / Booking / Offline)

 Occupancy Chart: Monthly occupancy trend

 Revenue by Room Chart: Performance of each room

⚙️ 4. Settings Page

Create a configuration panel for easy system control:

 Number of rooms (editable list)

 Currency selection

 Number of days in a month

 General system settings

📅 5. Monthly Summary Page

A comparison dashboard showing all months in one view:

 Monthly revenue comparison table

 Monthly booking count comparison

 Occupancy rate per month

 Trend indicators (increase/decrease)

✨ Advanced Features (Must Include)

 Month selector dropdown (dynamic switching between months)

 Fully automatic calculations across all sheets

 Professional conditional formatting rules (high/low performance highlighting)

 Consistent color palette and modern UI design

 Locked/protected cells for formulas to avoid accidental edits

 Fully responsive design (mobile + desktop friendly)

 Scalable structure for future expansion

🎯 Goal

The system should feel like a professional hotel management SaaS dashboard, not a simple spreadsheet. It should be clean, automated, visually intuitive, and ready for real business use.
